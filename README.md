#Dashboard: Análisis de Ventas – Carlos Guzmán (00308624)

## Descripción
Este dashboard permite analizar el rendimiento de ventas de una concesionaria de autos, mostrando:
- Canales más efectivos
- Modelos más vendidos
- Variación de ventas anuales
- Desempeño por vendedor
- Desempeño por vehículo

## Uso
Para seleccionar un solo tipo de información (ya sea modelo, año, vendedor, etc) basta con hacer click en cualquier tabla que incluya este tipo, las tablas se corregirán automáticamente para mostrar solo lo relacionado a esto.
